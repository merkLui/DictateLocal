## [0.1.0] - 2026-11-07

First public release.

### Added

- Dictation into any app from the menu bar with a configurable shortcut: hold to talk, tap to start and stop, or both.
- On-device speech recognition with NVIDIA Nemotron (types while you speak) or Parakeet Ultra (inserts the text when you stop).
- Live typing in Chromium-based browsers.
- Optional text improvement on the Mac with Spokenly Cleanup and rule-based list formatting, or online with Claude Haiku using your own Anthropic API key, with adjustable reasoning and an editable prompt.
- Vocabulary replacements for words the model keeps getting wrong.
- Settings in the style of System Settings, with info buttons that explain each option, including disk and memory use per model.

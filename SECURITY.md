# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub's vulnerability reporting](https://github.com/merkLui/DictateLocal/security/advisories/new) instead. You will get an answer within a week, and a fix is released as soon as it is ready, with credit to you if you like.

## Scope

DictateLocal records audio, reads the focused text field through Accessibility, sends keystrokes and, if enabled, sends text to the Anthropic API. Issues that let another app or a website abuse these abilities, leak dictated text or the API key, or run code through a downloaded model or update are in scope.

Only the latest release is supported.
